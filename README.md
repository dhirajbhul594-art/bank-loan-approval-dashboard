# Bank Loan Approval Dashboard

A 3-page Power BI dashboard built to analyze loan application data, uncover approval and credit risk trends, and support data-driven lending decisions.

## Overview

This project analyzes **70,000+ loan applications** to understand what drives loan approvals and rejections. The dashboard combines interactive visuals with DAX-based calculated measures to give a clear, decision-ready view of approval rates, credit risk, and overall portfolio value.

## Objective

Financial institutions need to quickly understand patterns in their loan portfolio — which applicant segments have higher approval rates, where credit risk is concentrated, and how factors like education or loan intent affect outcomes. This dashboard was built to turn raw loan application data into these insights through visual, interactive reporting.

## Key Features

- **3-page interactive dashboard** covering portfolio summary, risk analysis, and applicant segmentation
- **DAX measures** for:
  - Loan approval rate
  - Credit risk scoring/classification
  - Total portfolio value (~$379M analyzed)
- **Trend visualizations** across:
  - Credit bands (risk categories)
  - Education level
  - Loan intent/purpose
- Drill-down capability to explore approval and rejection patterns at a granular level

## Tools & Technologies

- **Power BI** — dashboard design, data modeling, and visualization
- **DAX (Data Analysis Expressions)** — calculated measures and KPIs
- **Power Query** — data cleaning and transformation

## Dataset

The dataset includes 70,000+ individual loan applications with attributes such as credit band, education level, loan intent, and application outcome (approved/rejected), representing a total portfolio value of approximately $379M.

## Key Insights

- Identified how credit risk varies across different credit bands, helping highlight which segments carry the highest lending risk
- Analyzed the relationship between applicant education level and loan approval likelihood
- Examined loan intent (purpose of the loan) as a factor influencing approval/rejection decisions
- Surfaced portfolio-level metrics to support high-level decision-making on lending strategy
